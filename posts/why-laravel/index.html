为什么选择 Laravel？

Laravel 是一个语法清晰、优雅的 Web 应用框架，为应用开发提供完整的基础结构，让你专注于实现业务。

Haijian Peng2020年5月10日 · 约 14 分钟阅读

本文根据原有英文内容翻译，保留原发布日期。文中的 SQLite 默认配置、Herd 和 Sail 等说明属于较新的文档语境，资料链接对应 Laravel 11.x，使用时请结合实际版本。

认识 Laravel

Laravel 是一个语法清晰、优雅的 Web 应用框架。Web 框架为应用提供基础结构和开发起点，处理通用细节，让你能够专注于创造有价值的功能。

Laravel 希望在提供强大功能的同时，带来出色的开发体验。它具备完善的依赖注入、表达力丰富的数据库抽象层、队列与定时任务，以及单元测试和集成测试等能力。

无论你刚开始接触 PHP Web 框架，还是已经积累了多年经验，Laravel 都能够伴随你成长。它既能帮助你迈出 Web 开发的第一步，也能支持你进一步提升专业能力。

刚接触 Laravel？可以通过 Laravel Bootcamp 的实战教程，一步步构建自己的第一个 Laravel 应用。

为什么选择 Laravel？

构建 Web 应用时，有许多工具和框架可供选择。原文认为，Laravel 是构建现代全栈 Web 应用的理想选择。

渐进式框架

Laravel 常被称为“渐进式”框架，意思是它能够随着你的能力与需求一起成长。刚开始学习 Web 开发时，丰富的文档、指南和视频教程可以帮助你循序渐进地掌握基础，而不必一开始就面对所有复杂性。

对于经验丰富的开发者，Laravel 提供了依赖注入、单元测试、队列、实时事件等成熟工具。它针对专业 Web 应用进行了优化，也能支持企业级工作负载。

易于扩展的框架

Laravel 具有良好的扩展能力。PHP 的运行方式便于扩展，Laravel 也内置了对 Redis 等高速分布式缓存的支持，因此横向扩展相对容易。原文提到，已有 Laravel 应用通过扩展处理了每月数亿次请求。

如果需要更大规模的扩展，Laravel Vapor 等平台可以帮助你在 AWS 的无服务器基础设施上运行 Laravel 应用。

社区驱动的框架

Laravel 整合了 PHP 生态中优秀的软件包，提供成熟、对开发者友好的开发体验。来自世界各地的开发者不断为框架贡献代码。也许有一天，你也会成为贡献者之一。

初始配置

Laravel 的配置文件存放在 config 目录中。各选项都有相应说明，你可以浏览这些文件，了解可用配置。

Laravel 开箱即用，几乎不需要额外配置就可以开始开发。不过，建议检查 config/app.php 及其说明，按项目需求调整 timezone、locale 等选项。

基于环境的配置

应用在本机和生产服务器上运行时，许多配置值可能不同，因此重要配置通常通过项目根目录的 .env 文件设置。

不应将 .env 提交到版本控制中。不同开发者或服务器可能需要不同的环境配置；如果有人取得代码仓库的访问权限，文件中的敏感凭据也可能随之泄露。

关于 .env 和环境配置，详见配置文档。

目录配置

Web 服务器应将 Laravel 的 public 目录配置为站点根目录，避免把整个项目目录对外开放。不要尝试以项目目录作为公开目录，再通过其子目录访问应用，否则可能暴露敏感文件。

使用 Sail 通过 Docker 安装

无论使用哪种操作系统，Laravel 都希望让入门过程尽量简单。除了其他本地开发方式，它还提供了 Sail，帮助你使用 Docker 运行项目。

Docker 可以在轻量的“容器”中运行应用和服务，不干扰本机已经安装的软件与配置。这样就不必在本机逐一配置 Web 服务器、数据库等复杂开发工具。入门时需要先安装 Docker Desktop。

Laravel Sail 是与默认 Docker 配置交互的轻量命令行工具。即使没有 Docker 使用经验，也可以借助它开始构建使用 PHP、MySQL 和 Redis 的 Laravel 应用。

熟悉 Docker？可以通过项目中的 docker-compose.yml 自定义 Sail 的各项配置。

下一步学习什么，也取决于你计划如何使用 Laravel。下面介绍两种主要使用方式。

初次接触框架时，也可以通过 Laravel Bootcamp 实战教程构建第一个应用。

将 Laravel 用作全栈框架

Laravel 可以用作全栈框架：由它处理路由，再通过 Blade 模板渲染前端，或结合 Inertia 构建融合单页应用体验的站点。这是使用 Laravel 的常见方式，原文也认为这种方式具有较高的开发效率。

如果选择这条路线，可以阅读前端开发、路由、视图和 Eloquent ORM 文档。也可以了解 Livewire 和 Inertia 等社区项目，在全栈开发中使用单页应用常见的交互能力。

还建议学习使用 Vite 编译应用的 CSS 和 JavaScript。

想更快开始开发，可以查看官方应用启动套件。

将 Laravel 用作 API 后端

Laravel 也可以为 JavaScript 单页应用或移动应用提供 API 后端。例如，可以为 Next.js 应用提供身份验证和数据存储、读取能力，同时使用队列、邮件、通知等服务。

如果采用这种方式，可以进一步阅读路由、Laravel Sanctum 和 Eloquent ORM 文档。

希望快速搭建 Laravel 后端和 Next.js 前端？原文提到 Laravel Breeze 的 API 方案，以及配套的 Next.js 前端实现，可作为开发起点。
